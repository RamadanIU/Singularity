# Правила работы с репозиторием Singularity

## Изменения — только через Pull Request
- Никогда не пушить напрямую в `main`.
- Любые изменения: отдельная ветка → коммиты → push → Pull Request в `main`.
- PR создавать всегда, даже для небольших правок. Сливает PR владелец репозитория.

## Общение
- Отвечать по-русски.
- Объяснять простым языком, что изменено и почему это нужно.

## Перед PR
- Прогнать тесты: `python -m pytest -q tests/`
  (браузерные тесты мобильного чата: `CHROMIUM_PATH=<путь к chromium> python -m pytest -q tests/test_mobile_html.py`).
