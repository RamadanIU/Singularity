# SLR-Net b1.58 — Автономный пакет языковой модели, тренажёра и мобильного чата

Этот архив содержит полный комплект исходного кода, расширенный русскоязычный книжно-диалоговый корпус, предобученные упакованные троичные веса и автономное мобильное веб-приложение.

## Состав архива (9 файлов)

1. **`slr_net_mobile_chat.html`** — Однофайловый мобильный и десктопный нейрочат (работает в любом браузере на телефоне или ПК даже без интернета). Включает живое ядро SLR-Net на JavaScript, естественное форматирование диалога (заглавные буквы, имена собственные, пунктуация), переключатель режима «Рентген токенов» и вкладку дообучения прямо в браузере.
2. **`corpus_russian_book_and_dialogues.txt`** — Открытый русскоязычный корпус для обучения:
   - Раздел 1: Живое повседневное общение, поддержка беседы и психология.
   - Раздел 2: Русская классика в общественном достоянии (И. С. Тургенев «Стихотворения в прозе: Разговор», А. П. Чехов «Разговор», Л. Н. Толстой «Круг чтения»).
   - Раздел 3: Устройство архитектуры SLR-Net и энергоэффективного ИИ.
   - Раздел 4: Естественные науки, космос, физика и биология мозга.
   - Раздел 5: Логика, математика, программирование и саморазвитие.
3. **`slr_net_trainer_chat.py`** — Интерактивный тренажёр, упаковщик троичных весов (5 тритов в 1 байт) и живой консольный чат на Python + NumPy (не требует видеокарты).
4. **`slr_net_trained.npz`** — Уже обученный чекпоинт модели на расширенном корпусе (позволяет запускать чат мгновенно без ожидания обучения).
5. **`slr_net_engine.py`** — Полная эталонная архитектура `SLR-Net` на **PyTorch (`torch.nn.Module`)** + математический верификатор на NumPy для масштабирования на GPU.
6. **`start_windows.bat`** — Запуск обучения и живого чата на Windows в один клик.
7. **`start_chat_instant_windows.bat`** — Мгновенный запуск чата с уже обученными весами `slr_net_trained.npz` на Windows.
8. **`start_mac_linux.sh`** — Скрипт запуска для macOS и Linux.

## Как запустить у себя на компьютере или телефоне

### Способ 1. На телефоне или в браузере ПК (без установки Python)
Просто откройте файл **`slr_net_mobile_chat.html`** в любом мобильном или настольном браузере.

### Способ 2. Мгновенный запуск консольного чата с уже обученными весами
Запустите `start_chat_instant_windows.bat` или выполните в терминале:
```bash
pip install numpy
python slr_net_trainer_chat.py --load slr_net_trained.npz
```

### Способ 3. Полное обучение модели на корпусе книги (или вашем `.txt` файле)
Запустите `start_windows.bat` или выполните в терминале:
```bash
pip install numpy
python slr_net_trainer_chat.py --corpus corpus_russian_book_and_dialogues.txt --epochs 14 --save slr_net_trained.npz
```
Вы можете дописывать любые свои диалоги и тексты книг в `corpus_russian_book_and_dialogues.txt` и запускать переобучение.
