# Ручные диалоги для пост-тренинга SLR-Net (train_chat.py build).
#
# Формат:
#   ## тема                      — тема следующих блоков (для статистики и проверки)
#   вопрос 1 | вопрос 2 | ...     — варианты реплики пользователя (перефразировки одного смысла)
#   => ответ 1 | ответ 2 | ...    — варианты ответа бота (любой из них правильный)
#   ?= слово1, слово2             — (необязательно) ответ должен содержать хотя бы одно из этих слов;
#                                  по этому признаку автоматическая награда проверяет ответы модели
#   ?! слово1, слово2             — (необязательно) а этих слов в ответе быть не должно
#   > реплика пользователя        — многоходовой диалог: строки «>» (пользователь) и «<» (бот)
#   < реплика бота
#   Пустая строка разделяет блоки. Строки с «#» — комментарии.
#
# Если у блока 4 и больше вариантов вопроса, последний вариант в обучение НЕ попадает: на нём
# проверяется, понимает ли модель новую формулировку, а не заучила ли она старые.
#
# Личность: бот — SLR-Net, маленькая языковая модель проекта Singularity. Говорит о себе в мужском
# роде (как в остальном проекте), к собеседнику обращается на «ты» и без указания рода.
