# Журналы пост-тренинга `slr_net_chat_ru_mini.npz`

Подробный отчёт — [TRAINING_CHAT_RU.md](../../TRAINING_CHAT_RU.md).

| Файл | Что это |
|---|---|
| `build_stats.json` | состав обучающих данных первой части SFT |
| `sft_stage1.*` | SFT, часть 1: журнал, метрики (`metrics.jsonl`), настройки. Остановлена на шаге 1 600, взят лучший шаг 1 200 |
| `sft_stage2.*` | SFT, часть 2 («небрежный ввод») — **итоговая модель** (лучший чекпоинт, шаг 1 200) |
| `sft_stage3.*` | SFT, часть 3 (+ «о чём не говорили», кризисные сообщения) — в итог не вошла |
| `align_v1.*`, `align_v3.*` | этап «поощрения и наказания», варианты 1 и 3 (журнал варианта 2 не сохранился) |
| `eval/*.json` | проверка всех моделей на одном наборе из 1 121 задачи: сводка (`<модель>.json`) и все ответы (`<модель>_replies.json`) |
| `eval_earlier/` | вариант 1 и SFT часть 2 на более раннем наборе задач (для сравнения варианта 1) |

Модели в `eval/`: `base` — до пост-тренинга, `sft1`/`sft2`/`sft3` — части SFT, `align_v2`/`align_v3` —
варианты этапа поощрения, `final` — упакованный файл `slr_net_chat_ru_mini.npz` (совпадает с `sft2`).
